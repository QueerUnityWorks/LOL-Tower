# 原作主题配置补充

本版采用《金铲铲之战》中的金铲铲之战与艾欧尼亚林地设定。
角色、敌人表使用 `appearanceId`（简化头像标识）、`skillName`（技能显示名）、`biography`（介绍），并新增 `skillKind`、`skillPower`、`trait`、`traitPower` 配置技能与特性。修改技能名只改变显示，实际机制由后四列决定。
初始角色仍引用 `HERO_001`，现为亚索；所有节点、效果、奖励池与商品通过原有稳定 ID 关联。
事件 CG 使用 `EventCG/cave`、`EventCG/village`、`EventCG/tempest`、`EventCG/grove`、`EventCG/forge`、`EventCG/wolves`、`EventCG/training`、`EventCG/hoard`、`EventCG/caravan`，可替换对应图片而不修改事件逻辑。表中简介为新写的游戏文案。
稀有度是本局招募与掉落分级，不对应原作实力排序。生命条保持红色，技力条保持蓝色。

# 配置库使用说明

## 2026-11-16 生命与道具调整

每次新冒险初始有3点冒险生命，与角色战斗生命分别计算。战败结算立即扣1点；重新布阵、重试及正常调整站位不扣命，平局不扣命。生命耗尽后本次冒险结束，无法重试或进入地图节点，返回主城后可开始新冒险；正式冒险失败保存在冒险记录中。生命随冒险存档保存，旧存档缺少生命字段时按3点迁移。新手试炼使用独立的3点生命，不影响暂停保存的正式冒险。

全部30件增益道具使用当前战斗规则重新测算，每件按全队6名亚索、持有1件的场景测量，增益系数最低为1.1006877973。该系数仅作为强度评估元数据，战斗应用实际效果数值。负面与剧情道具不纳入1.1下限。

效果表增加 `bonusAttack` 字段：速度道具在原有速度加成之外额外增加的全队攻击，按持有数量叠加；其他效果填0。反曲之弓为速度+10、攻击+25，疾射火炮为速度+18、攻击+30，轻灵之靴为速度+18、攻击+25。旧配置缺少此列时导入默认为0。修改后须成对同步 `GameContent.xlsx` 与 `HandbookBalance.json`，再执行 `Import Synced Handbook`。

## 编辑与导入

游戏使用 `Assets/ElementalTactics/Data/GameContent.xlsx`。修改并保存后，退出Play模式，点击Unity菜单 `Tools → Elemental Tactics → Import Game Workbook`。

导入器先验证所有表、唯一ID、跨表引用、数值、CG资源、等级概率、商店配置、奖励池和四层地图覆盖及结局解锁规则，再更新 `Assets/ElementalTactics/Resources/Data` 下的14个SO库。重新导入保留现有SO的GUID。无需重新生成三个场景，从StartScene开始新旅程即可使用新配置。

16张运行配置表的第1行标题，第2行说明，第3行程序字段，第4行中文标题，第5行起为数据。不要修改这些工作表名和第3行字段名；运行配置使用固定值，不填写公式。新增记录必须有唯一ID，不能通过复制一行保留原ID。英文枚举为代码标识，玩家界面使用中文。

## 战力与收益估值

工作簿另含七张策划分析表：战力规则、单位战力、阵容测算、收益估值、奖励预算、节点估值、关卡难度。分析表允许公式，导入器仅处理16张运行配置表，不把分析表写入SO。关卡难度实时计算四个楼层的实际敌阵战力与生效奖励配置；战力规则C78选择节点估值使用的楼层。奖励预算保留旧rewardId预算参照，不代表新的按难度奖励。

统一战力为 `K × SQRT(全队有效每轮输出之和 × 全队有效承伤之和)`。K按独立标准战士归一到1000点；六个标准战士为6000点。有效输出计入普攻次数、技能次数、倍率、平均命中、属性环境、参考防御、狂暴和有限的先手权重；速度只改变先手权重，不增加行动次数。有效承伤计入生命、防御、开战护盾、治疗、吸血、再生和技能护盾；治疗及多目标伤害使用可校准的利用率。单项收益为获得后队伍战力减获得前队伍战力。

角色评级使用加入五名标准战士阵容后的增量；道具评级使用六名标准战士首次获得一件后的增量。角色稀有/史诗门槛为1100/1300，道具为250/600，等于门槛进入较高档。门槛在战力规则中可调。角色原有数值不因重新评级再乘稀有度倍率；元素默认按中性环境评价，评级不对应原作实力。收益估值保留原稀有度、计算结果和当前运行配置稀有度供比较。

黄色区域可填写当前阵容、背包数量、金币、等级经验和已走节点数。每个角色尝试六个替换位置并允许不上阵；道具分别联合重算获得1件和2件的收益；重复二连击增益为0，空位补人与满员替换会给出不同结果。此处为策划示例，不自动读取正在运行的游戏状态。

金币和经验的即时战力为0，潜在价值分列。金币购买力来自当前道具商品标准战力增量/价格的中位数，再乘兑现折扣。经验按固定经验商品的金币成本折算并加折扣，满级及溢出部分不计收益；经验影响掉落概率，其潜在价值是预算代理量，不是直接属性。奖励估值先计算胜利升级后的抽取概率，再采用固定领取角色、可选两件时再取首件道具的策略，不声称计算了多个候选中择优的精确期望。多项收益的相加是预算近似，实际联合作用须更新阵容和背包重算。

节点估值包含敌阵战力和敌我战力比，新战斗奖励预算标记为待重估；生效奖励见关卡难度。事件按当前金币能执行的最高预算选项估值；商店按候选池内最佳可负担单次购买估算机会的上界，尚未扣除随机未上架风险。所列概率为给定楼层、排、同类型、首次抽取的条件概率，不含商店限制、保底、去重，也不代表玩家最终到达概率。

修改数值或模型参数后，Excel公式会重算，但运行表rarity保持固定值；需将收益估值中的计算稀有度按ID、按值同步到角色/道具表，再执行Unity导入。同步状态列会提示差异。新增记录时需扩展相关公式计算行和查询范围。模型是首版平衡依据，平均目标数、治疗利用率、先手收益应结合实战记录校准。

## 节点与路径

`Battle`引用战斗关卡ID，`Event`引用事件ID，`Shop`引用商店ID。`minRow`和`maxRow`为1至7，`weight`为正整数。普通节点`isFinal=false`，终点`true`且类型为Battle。

前三层各7排、19个节点；隐藏第四层3排普通节点加1排首领，共10个节点。总计67个节点；minFloor/maxFloor限定1至4层，minRow/maxRow受楼层rows限制。首排全战斗；普通排随机保底一个战斗，其他格按楼层类型权重抽取；同排优先使用不同内容。商店仅第3至5排出现，每层全图最多2家，默认保底1家，直接连线不连续遇店。权重受这些限制影响，不等于全图最终占比。

保留同路向上连接，第2至5排各尝试增加一条相邻路线连接，双商店连线跳过。第六排汇入守关节点；第1至2层分别固定BATTLE_003、BATTLE_011，第3层默认BATTLE_012，持有破败王冠时为BATTLE_027，完成并领奖后连接下一层三路。生命/攻击倍率依次100/100%、135/125%、175/155%，生命相关治疗/特性同步缩放。跨层不清空本局状态。

生成规则位于`Runtime/Map/MapRun.cs`。`ResetWithSeed(int)`可复现路线和奖励；新旅程自动换种子。未解锁节点显示类型图标，具体内容仍隐藏。

难度掉落表按敌方实际战力匹配最高已达门槛：普通0、精英2500、高危5500。普通道具池只含普通/稀有，高危只含稀有/史诗；池内仍按冒险等级概率抽稀有度，缺失档归一化。战斗关卡新增itemPoolId/characterPoolId，空白表示使用难度池；itemCandidates/characterCandidates/chooseCount填-1继承，填0为明确关闭。最多6候选，可选数不能超过候选总数。默认3选1、4选2、5选2；三层Boss分别5选2、5选2、5选3。rewardId仅提供金币与经验公式。

- BATTLE_002：诺克萨斯重卫、诺克萨斯突击兵、伊莉丝·蛛群稀疏阵形，基础金币40，每节点加7，3选1。
- BATTLE_003：第一层守关阵形，基础金币60，每节点加10，5选2。
- BATTLE_004至010：狼群围猎、岩甲关隘、迷雾蛛巢、树精秘境、狂鬼营地、翼蛇回廊、海克斯钢遗迹，使用REWARD_002。

## 敌人技能与特性

所有技能沿用3点技力：普攻行动获得1点，满值后下次行动释放。布阵中的敌方情报可查看每名敌人的技能说明与特性。

| skillKind | 机制 | skillPower |
|---|---|---|
| RoleDefault | 沿用职业默认技能 | 必须为0 |
| AllEnemies | 攻击所有存活敌人 | 攻击百分比，例如80表示80% |
| WeakestEnemy | 越过前排，攻击生命比例最低的敌人 | 攻击百分比 |
| AllAllies | 治疗所有存活队友，包含自己 | 固定回复生命值，不复活 |
| ArmorPierce | 单体攻击忽略防御，仍受护盾吸收 | 攻击百分比 |

自定义技能的skillPower范围为1至500；伤害仍计算属性克制。角色表也支持相同配置，现有12位角色保留原职业技能。

| trait | 机制 | traitPower |
|---|---|---|
| None | 无额外特性 | 0 |
| OpeningShield | 开战获得护盾，总护盾不超过最大生命 | 护盾值 |
| Regeneration | 每次行动开始回复生命，连击只触发一次 | 回复值 |

## 奖励计算

金币 = goldBase + goldPerNode × 进入本节点前已完成的节点数。首战30金币；完成前六层再通过终点获得120金币。完成的事件和商店也计数。

先按当前冒险等级抽稀有度，再按池内同稀有度条目的weight抽取，抽中目标从候选中移除，数量在最少/最多之间随机。某稀有度不存在或耗尽时，仅对剩余稀有度按比例抽取。各池目标ID不能重复，最多6个候选。可放弃候选，金币仍在确认时发放；首次胜利固定结果，重复点击不会重复发放。

## 等级与稀有度

等级为本局冒险等级，非角色个人等级。初始1级，样例上限10级。升下一级所需经验依次为50、75、100、125、150、175、200、225、250；满级填0。允许一次跨多级，溢出保留，满级经验归零。升级不直接改变角色属性。

胜利经验 = experienceBase + experiencePerNode × 进入前已完成节点数，当前全部关卡均为20 + 10 × 节点数。第一战获得20经验，终点战获得80经验。胜利立即入账一次，再按升级后的等级生成战利品；确认奖励不重复加经验。失败、平局和退出没有胜利经验。

角色与道具的rarity使用Common、Rare、Epic，对应普通、稀有、史诗。等级表概率合计100，全部为正，等级从1连续递增；等级提升时普通概率不得增加、史诗概率不得降低。

| 等级 | 普通 | 稀有 | 史诗 |
|---|---:|---:|---:|
| 1 | 80% | 18% | 2% |
| 5 | 60% | 26% | 14% |
| 10 | 35% | 36% | 29% |

实际每次抽取概率在候选缺少某级别时会重新归一化，不放回抽样也会改变后续格子的概率。商店随机货物和战利品共用等级概率。角色和道具稀有度现按标准环境战力增益分档，具体评级见收益估值表；基础数值直接存角色表，不在运行时按稀有度重复乘算。

## 事件、效果和商店

CG填写相对Resources的路径，无扩展名，例如`EventCG/grove`。九个事件各有程序绘制的原型插画：海克斯遗迹、弗雷尔卓德营地、金铲铲议事厅、艾翁的委托、奥恩的锻炉、祖安暗巷、无极剑道试炼、星界宝库、受困的商队。每个事件1至3个选项，以`order`排序，显示在竖屏下方，可获得道具、角色、金币或经验，也可组合金币消耗与奖励。

多个效果ID用英文分号分隔，例如`FX_COST20;FX_ITEM03`。先验证整组选项全部效果，成功后执行，金币不足时按钮禁用且不产生部分奖励。

| GiveCharacter | 角色ID | 获得卡片数，同角色可重复，每张实例ID独立 |
| AddGold | 留空 | 增加金币数 |
| SpendGold | 留空 | 消耗金币数，不能透支 |
| AddExperience | 留空 | 立即获得冒险经验，不进入背包 |
| AttackBonus | 留空 | 每件道具为全队增加的攻击值 |
| HealthBonus | 留空 | 每件道具为全队增加的最大生命值 |
| HealthPenalty | 留空 | 每件道具扣除的最大生命值，最终最低1 |
| DefenseBonus | 留空 | 每件道具为全队增加的防御值 |
| SpeedBonus | 留空 | 每件道具为全队增加的速度值 |
| DoubleAttack | 留空 | 固定填写1，开启普通攻击二连击，不叠加 |

## 结局解锁与单次事件

结局规则表导入 Endings.asset。ENDING_001 为默认结局；EVENT_010 在祝福枝与破败王冠 ITEM_031 之间二选一，持有后第三层替换为二结局首领。EVENT_011 提供契约 ITEM_032；持有契约进入并战胜3个不同战斗节点，各必得1枚 ITEM_033（最多3枚），同时持有契约和3枚印记后开放第四层，击败 BATTLE_028 达成三结局。第三层首领仍独立由破败王冠决定。

节点字段 uniquePerRun 表示每种特殊事件单局仅可进入一次，不限制生成数量；guaranteed 仍表示指定排保底出现。进入后立即消费机会，其余同类节点替换为符合所在排的普通事件，保留节点ID与连线。中途退出也不能再进入同一特殊事件。新旅程清空记录。解锁道具与印记均排除普通奖励池和商店；解锁道具只能由对应事件给出，印记由胜利结算自动发放，不占可选奖励数。
