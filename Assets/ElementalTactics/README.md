# 金铲铲之战 · 符文远征录

当前为《金铲铲之战》原作设定的同人战术原型，中文界面，1080×1920 竖屏。

开始界面采用绿色森林、暖黄色土地与林间小路，搭配远方城镇、魔法阵及发光亚索主视觉；上方是金铲铲之战标题，下方只有一个金边绿色“开始游戏”操作按钮，点击进入地图。亚索轻微漂浮，符文能量光点缓慢上升；美术使用原生矢量网格，无需外部图片资源。可用 `Tools → Elemental Tactics → Rebuild Start Scene` 单独重新生成。

地图右下角“放弃”按钮结束当前旅程并返回开始界面，同时重置金币、背包、角色、等级经验、布阵与路线进度。再次开始游戏进入全新旅程。

- 初始伙伴为亚索；12 位伙伴包括布隆、拉克丝、艾希、蕾欧娜、图奇、瑟庄妮、盖伦、易、阿狸、奥瑞利安·索尔、金克丝。
- 内容库现有35种敌人、33种道具、28个战斗关卡、15个事件；16张Excel运行表通过14个SO库加载，策划分析表不写入SO。
- 深蓝鎏金界面、海克斯城邦背景、按角色区分的简化矢量头像，以及九张程序绘制的事件插画。美术为原型资源，尚非完整角色立绘或动画 CG。
- 主城排行榜、每日挑战与新手教程使用同款224×78入口卡片。教程使用淡紫色翻页手册与指引星光图标，副标题“阿狸带你入门”；教学进行中显示“继续教程 / 返回教学远征”，保留悬停、按下和点击音效。
- 角色与敌人表包含 `appearanceId`、`skillName`、`biography`，并用 `skillKind`、`skillPower`、`trait`、`traitPower` 配置技能与特性。角色面板展示介绍，敌方情报显示实际技能效果及特性。所有原有唯一 ID 和效果引用保持稳定。
- 职业技能、火水草克制、稀有度与数值属于本游戏适配，稀有度不代表原作战力。原作角色背景采用重新编写的游戏文案。
- 六人布阵、拖拽交换、上次布阵恢复、红色生命条、蓝色技力条、回合提示、三路节点、背包、等级经验、奖励与九格商店继续使用。

# 金铲铲之战：竖屏战斗原型

打开 `Scenes/StartScene.unity`，按 Unity Play。流程为开始游戏 → 三路地图 → 战斗 / 事件 / 商店 → 获得奖励并推进路径。配置管理见 `Data/配置管理说明.md`。

## 操作

- 每局以1名初始角色开始；下方候补列表每行四张，从左到右、从上到下排列，支持上下拖动、鼠标滚轮及右侧滚动条。重置布阵时返回列表顶部。
- 点击候补角色会在顶部弹出属性、数值、职业和技能介绍；再点击上方阵位上阵或替换已有队员。
- 已上阵角色不显示在候补列表中，剩余角色自动按每行四张补齐空位；撤下或被替换的角色按原顺序回到列表。列表高度随候补数量调整。
- 本局自动保留上次六格布阵，包括空位：点击上阵、撤下、拖动交换后立即保存，返回地图、下场战斗或重试时恢复。按角色实例ID区分同名卡，新获得角色留在候补。重置布阵会保存重置结果；开启新旅程恢复初始单人阵容。当前仅在本次运行期间保留，不跨退出游戏存档。
- 选中已上阵角色再点其他阵位可移动/交换；点击角色后，在屏幕中下方弹出详情，展示头像、属性、职业、站位和技能，较长技能说明可滑动查看。点击“收起”保留选择，仍可点阵位布阵；“取消选择”清除选择，“撤下伙伴”返回候补。空阵位显示加号。
- 支持拖动布阵：鼠标直接拖动候补卡片；手机长按候补卡片约0.3秒再拖动（直接上下滑动仍浏览列表）。已上阵角色可直接拖动到空阵位，或拖到另一名角色上交换位置。
- 候补拖到已占用阵位会替换原角色，原角色返回候补；拖到阵位外松手取消操作。拖动时显示卡片预览和目标阵位高亮，点击布阵仍可使用。
- 右侧「敌方情报」按钮打开遮罩调查报告，点击敌方卡片查看详情，再返回布阵。
- 双方均为前卫三格、后卫三格。
- 点击开始战斗锁定布阵，右上角可切换1倍/2倍动画速度。
- 空阵位不会生成出战卡片。敌方前排在下、后排在上，敌情预览与实际战斗一致；结算存活人数按本场实际上阵人数统计。
- 战斗顶部显示本回合尚未行动角色的顺序，正在行动者加括号。攻击目标出现红色高亮，盾卫技能的治疗及护盾目标出现绿色高亮。
- 下方战报保留最近三条显示，记录普攻、技能、伤害、格挡、治疗、护盾及阵亡；本场内存最多保留80条。
- 点击“暂停 / 退出”或按Esc暂停，动画、伤害结算、技力与回合计时一起停止；返回应用后需手动继续。退出到地图需再次确认，本场进度不保留。
- 先前排、同排优先同列；按照速度依次行动，每轮每人一次。同速顺序在开战时随机，本场固定。
- 普攻增加1能量，满3点后下次行动自动放技能。最大50轮，超过则平局。
- 生命值条统一为红色，技力条统一为蓝色（满条也保持蓝色）。战斗卡片在生命值下方显示技力条和技能回合倒计时；根据本回合是否已行动显示“距技能N回合”“下回合释放技能”或“本回合释放技能”。技能消耗后重新计时，阵亡角色停止显示倒计时。
- 每回合开始前弹出“第XX回合 · 开始”，固定显示0.5秒后角色开始行动，两倍战斗速度不会缩短提示时间。
- 回合提示按未暂停的时间累计0.5秒，暂停期间不推进。
- 火克草、草克水、水克火。优势倍率1.25，逆克制0.8，同属性1。
- 伤害 = 攻击 × 技能倍率 × 属性倍率 × 100 / (100 + 防御)，四舍五入，至少1。护盾先承伤。
- 战士单体吸血；法师攻击一排；盾卫治疗生命比例最低的队友并加盾；射手穿透一列。
- 敌人可覆盖职业默认技能，使用全体攻击、残血追击、全体治疗、无视防御的单体攻击；可附带开战护盾、行动再生、半血狂暴、普攻二连击、吸血特性。技力规则保持一致，布阵时可先查看敌情。
- 治疗不复活、不超过生命上限，护盾可累积但不超过最大生命值。

## 地图阶段

- 地图使用1080×1920竖屏中文界面。三大层依次为艾欧尼亚林地、诺克萨斯前线、暗影岛深域；每层六排三路汇入第七排守关战，每层19个节点。普通结局路线经过21个节点。满足契约条件可进入隐藏第四层：三排三路节点汇入第四排首领，共10个节点；隐藏结局路线经过25个节点。
- 地图左侧“角色”按钮打开本局角色列表，已上阵与候补均显示，同名卡分别展示；每行四张，支持上下滑动和右侧滚动条。点击卡片查看职业、属性、包含道具加成的数值和技能，并标注保存阵容中的位置。此窗口仅查看，不改变布阵；关闭按钮或Esc返回地图。
- 初始可选最下层任意一路；战斗领取奖励、完成事件选择或结束购物后，仅解锁当前位置直接连接的下一层节点。点击蓝色节点在下方显示关卡介绍与“进入关卡”按钮。
- 所有节点均显示类型图标：交叉刀剑为战斗、问号为事件、摊位为商店。未解锁节点只公开类型，隐藏具体内容，不提供进入按钮；已完成节点不能重复进入。
- 失败、平局或退出不推进地图，可再次挑战；最后一关胜利后可开启新旅程。从开始场景点击开始旅程会重置地图。
- 每层首排全战斗，后续普通排保底一场战斗；其他格按楼层权重生成。前三层商店仅在第3至5排出现，第四层仅在第3排出现；每层全图保底1家、最多2家，连线不会连续经过商店。中段随机跨路连接，最后一排三路汇入守关节点；击败守关敌人并领取奖励后解锁下一层，保留角色、背包、等级、金币与布阵。
- 事件包含CG、介绍和1至3个选项；选择后执行效果表。商店按具体地图节点保存库存，购买扣除金币并获得道具或角色，结束购物推进地图。
- 当前配置包含35种敌人、28种战斗、15种事件、33种道具与12名可招募角色。新增各层专属敌阵、海克斯工坊、战地救护站、破败遗藏与星界馈赠；剧情道具不进入随机奖励池或商店。
- 战斗按关卡表六个位置加载敌人，并应用楼层生命/攻击倍率。实际敌阵战力决定奖励档位：2500以下普通，2500起精英，5500起高危；档位控制道具池、角色池、候选数和可选数。关卡可单独覆盖这些设置；前三层守关战分别从5个候选选2、2、3项。金币与经验随全旅程已完成节点数增长，奖励只发放一次。
- 旧版MapScene无需重新生成：SceneNavigation运行时创建新地图并隐藏旧界面。

## 冒险等级与商店

- 本局冒险等级从1级开始，上限10级；升级不直接增加角色属性。战斗胜利立即获得经验：20 + 进入本节点前已完成节点数 × 10。事件和商店计入已完成节点数。经验只发放一次，领取战利品不重复加经验。
- 角色与道具分普通、稀有、史诗三级，使用灰、蓝、紫标识。等级1的普通/稀有/史诗概率为80%/18%/2%，等级10为35%/36%/29%；先抽稀有度，再从该稀有度候选按权重抽取。缺失的稀有度按剩余权重归一化。升级后的本次战利品及以后商店刷新使用新概率。
- 商店使用3×3网格，最多九件货物。固定出售“海克斯经验宝典”：20金币获得40经验，每轮库存3；购买后立即生效，满级后禁止购买。其余八格从商品池不重复抽取。
- 刷新首次15金币，同一商店每刷新一次加5金币；刷新重抽随机商品、补满库存并保留经验商品。金币不足不刷新、不扣钱；离开重进不会免费刷新。当前商品不会因升级自动重抽。
- 等级、经验、稀有度概率、胜利经验、商品池及刷新价格均可在Excel中调整，导入后生成SO。新旅程重置经验等级与刷新次数。

## 背包与道具

- 除初始界面外，地图、布阵和战斗界面左侧均显示“背包”按钮，打开后使用上下滑动列表与右侧竖向滚动条浏览道具。
- 新旅程从空背包开始；同一道具按ID叠加数量，点击条目显示介绍。数量归零时移除该条目。
- 道具跨地图、关卡和重试保留；开启新旅程时清空。当前仅保存在本次运行内，不包含退出游戏存档。
- 战斗中打开背包会暂停战斗；关闭背包后点击“继续战斗”恢复。背包遮罩阻止误操作底层地图与布阵，Esc可关闭。
- 事件、商店和战斗奖励通过效果系统调用 `InventoryState.TryAdd` 入包。道具作为全队被动加成，持有即生效，在进入下一场布阵时应用；背包显示持有数量对应的总加成，商店与奖励显示本次获得数量对应的加成。
- 巨人腰带：每株最大生命+40；晶体护腕：每枚最大生命+100；暴风大剑：每颗攻击+15；反曲之弓：每枚速度+10；锁子甲：每枚防御+8。数值按数量叠加，单项属性上限100万，仅影响己方。
- 鬼索的狂暴之刃：我方全体普攻连续攻击两次，每击独立移动和伤害反馈；第一击击杀目标后第二击重新选敌，敌人全灭则取消第二击。每次行动只增加1点技力，技能不连击，同类连击道具不叠加。新增角色也享受加成，重试不会重复累加数值，开启新旅程后全部清空。
- 新增开战护盾、每次行动回复、吸血道具，以及更多攻击、生命、防御、速度加成。例如钢铁烈阳之匣提供60护盾、救赎每次行动回复15生命、饮血剑吸血12%。护盾不超过最大生命，再生在二连击中仅触发一次，吸血按实际生命伤害计算且总比例不超过100%。30种普通道具进入对应奖励池与商店候选池，另有3种剧情道具。

## 首领与结局

- 第一层祖安怒兽·沃里克：每名存活友军提高自身伤害15%；第二层亡灵战神：每名阵亡友军使伤害提高15%，下次行动按新阵亡人数各恢复12%最大生命，阵亡部下不会被重复吞噬。
- 默认结局「符文之地的黎明」：第三层挑战加里奥，每两次行动重生护盾。
- 第一层第2排保证至少生成一个「艾翁与破败王冠」，随机占用非保底战斗的一路，可选择绕过。进入后可取自然之力（全队生命+140），或破败王冠（全队生命−70，最低1）。只有此事件能获得破败王冠；持有时第三层首领替换为破败之王·佛耶戈，胜利进入二结局「驱散破败黑雾」。佛耶戈技能对存活目标各夺取1点已有技力，并按夺取点数生成护盾。
- 第二层第2排保证至少生成一个「铸星龙王的契约」，同样可以绕过。选择契约后，在进入战斗及胜利时均持有契约，每战胜一个不同战斗节点额外必得1枚星界印记，累计最多3枚；失败、退出、重复调用胜利与领奖均不重复累计。印记立即入包，不占可选奖励次数，放弃可选奖励也不会丢失印记。
- 同时持有契约和3枚印记时，第三层首领仍按是否持有破败王冠决定，守关后继续进入第四层。第三层守关本身可以成为收集第3枚印记的战斗。第四层首领为失控奥瑞利安·索尔：每两次行动轮转水、草、火属性并加盾，首次存活降至半血时蓄满技力并加盾；击败后进入「与铸星龙王的约定」。
- 两个特殊事件允许在地图中重复生成，但每种每局只能进入一次，不强制进入。进入时立即记录，其余同类节点替换成普通事件并保留连线；中途离开也消耗本次进入机会。新旅程清空契约、印记、事件进度和结局状态。当前仅支持本次运行内保存。
- Excel新增「结局规则」，并扩展「敌人/角色」的首领机制参数、「节点」的保底生成/单局仅进入一次标志、「楼层规则」的总排数/可选楼层。导入后生成14张SO库。剧情解锁价值独立说明；即时战力仍用于普通道具和角色稀有度，负面道具保留负估值。

## 远征结算

- 生命耗尽时进入失败结算；尚有生命的单场战败仍可重新布阵。最终首领的战利品确认领取后，进入对应成功结局；解锁隐藏第四层时，第三层守关后继续探索。
- 四种结算分别使用暗红、金色、青绿、星蓝色主题，展示结局标题、最终六个阵位、实际携带道具及总评分。空阵位显示“未上阵”，星数表示角色品质；超过六种道具可左右滑动查看。
- 探索分＝通过节点数×200；战斗分＝获胜战斗数×400；三个成功结局的通关分分别为2000、2500、3000，失败为0。通用评分＝探索分＋战斗分＋通关分；最终评分＝通用评分×难度系数，合计后四舍五入。评分达到10000、7500、5000、2500时分别为S、A、B、C，否则为D。
- 结算快照随冒险存档保存；重启后可继续查看未确认的结算。“返回主界面”保留远征记录，“再来一局”沿用本次难度并清空本局进度。底部“分享”按钮仅作展示，暂不可点击。
- 编辑器菜单 `Tools → Elemental Tactics → Validate Settlement` 检查三条结局、失败重试、领奖时机、存档恢复、道具滚动和按钮，并将四种实际渲染图输出到 `Temp/SettlementValidation/`。

## 排行榜

- 主界面左上方的小按钮“排行榜”打开本地模拟榜，按最高分降序排列，同分并列，后续名次按人数顺延。当前玩家在榜内高亮，底部固定显示自己的名次与最高分；未完成正式远征时显示“未上榜”。
- `Data/SimulatedUsers.xlsx` 包含30名虚拟用户。编辑A至D列的编号、昵称、通用评分、难度后保存，Unity自动导入为 `Resources/Data/SimulatedUsers.json`；也可使用菜单 `Tools → Elemental Tactics → Import Simulated Users`。Excel中的难度系数、最高分和排名由公式计算，游戏使用相同规则。
- 通关与生命耗尽的正式结算自动更新个人最高分，较低成绩、新局与放弃远征不会清除纪录；最高分独立于最近50条远征历史保存。旧档可从已有结算或历史恢复成绩，教程不计分。
- 菜单 `Tools → Elemental Tactics → Validate Leaderboard` 验证评分、排名、存档与界面，并在 `Temp/LeaderboardValidation/` 生成截图。

## 每日挑战

- 主界面“排行榜”旁的“每日挑战”展示当天任务和开始按钮，固定难度10。北京时间每日零点更新；同一天使用相同日期种子生成地图，并使用同一组任务。当前使用设备时间，不连接服务器。
- 每天只发布一项独立任务，轮换内容包括：全程持有伙伴不超过4人、亚索实际参战至少11场不同战斗、赢得至少12场战斗、剩余至少2点生命通关。只需达成当天目标并通关，即完成本日挑战，各天的条件分别判定。
- 人数按整局持有峰值计算，出战、候补、重复伙伴都算，超过4人后本局该任务失败。亚索在开始战斗时计数，同节点重试、多名亚索同场都只算1次。胜场在确认战利品后记录。
- 地图与战前布阵显示任务进度，获得伙伴、开始战斗、领奖和战败后自动更新并随存档保存。达到次数时显示“待通关”；任务失败仍可继续远征。
- 普通远征自动暂存，放弃每日挑战或结算后返回主界面会恢复原进度。跨日继续沿用开局日期的地图与任务，结束后才开启今日挑战。“再来一局”重复原日期挑战。
- 允许反复挑战，保留最近30天的每日最佳成绩：优先完成任务数，同数量时取最高分。每日结算沿用现有四种结局，并显示完成任务数，也会更新个人最高分。
- 菜单 `Tools → Elemental Tactics → Validate Daily Challenge` 检查日期边界、同日地图、任务判定、存档、普通远征恢复及教程隔离，结果输出到 `Temp/DailyChallengeValidation/`。

Unity Game窗口预览请添加Fixed Resolution：Width 1080、Height 1920，选择该分辨率。Game窗口的Scale仅改变编辑器预览缩放，不改变游戏分辨率。
- `Editor/Scenes/PrototypeSceneBuilder.cs`：生成可编辑的真实场景对象，会覆盖同名原型场景。保存场景并退出运行模式后，可通过 `Tools → Elemental Tactics → Rebuild Battle Scene` 仅重新生成关卡场景；`Build Prototype Scenes` 会重新生成全部三个场景。
- `Editor/Validation/PrototypeValidation.cs`：战斗规则检查，可在编辑器调用 `RunModelChecks()`。
